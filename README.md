# 📦 English Box — לומדים מילים באנגלית

## איך מפעילים
1. צריך Python 3 במחשב (https://www.python.org/downloads — בהתקנה בווינדוס לסמן "Add Python to PATH").
2. **Windows:** לחיצה כפולה על `start.bat`.  **Mac/Linux:** `python3 serve.py`
3. בחלון יודפס כתובת כמו `http://192.168.1.23:8000/` — פותחים אותה בטלפון (באותה רשת Wi-Fi).
   אפשר גם ⚙️ הגדרות ← לסרוק את ה-QR.
4. בווינדוס, אם קופצת הודעת Firewall — לאשר גישה ("Allow access").

## עדכון רשימת המילים
- בקובץ `words.js`, או
- באפליקציה: ⚙️ הגדרות ← רשימת המילים (שורה לכל מילה: `english - עברית`).

ההתקדמות נשמרת בדפדפן של הטלפון.

## עדכון גרסה
בכל שינוי באפליקציה: לעדכן את אותו מספר גרסה ב-`version.json`, ב-`APP_VERSION` וב-`words.js?v=` שבתוך `index.html`.
טלפונים עם גרסה ישנה יטענו את החדשה אוטומטית (ההתקדמות נשמרת).
